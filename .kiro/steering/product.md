# Product: K8s 降灵会（K8s Séance）

- 一句话：召唤已挂掉的 K8s Pod 的亡灵，让它用第一人称讲自己怎么死的，最后自动生成故障复盘。
- 参赛：Kiroween 2026，Frankenstein 赛道（K8s 排障 + 降灵会聊天 + 自动复盘缝成一个怪物）。
- 用户：值班 SRE / 平台工程师 / 学 K8s 的开发者；以及需要在 3 分钟内看懂的评委。
- 原则：
  - 功能少而精；好玩是外皮，结论必须有证据（退出码、事件、日志行）。
  - 对集群默认只读。唯一的例外是「施法」：服务以 `--allow-resurrect` 启动时，降灵会页可以真的执行复活咒语（仅限演示集群，先 dry-run，权限用单独的命名空间 Role）。写操作全部集中在 `internal/rite`。
  - 能省则省：LLM 接口可配置、不绑定厂商，开发用 mock；严格限制调用次数和 token。
  - 没有集群也能演示（fixtures + 回放）。
- 不做：登录、多租户、SaaS、写集群、外部可观测性集成、多集群 UI。
- 人设语气：阴森、简短、带点黑色幽默，但技术事实准确；不吓人到看不懂。
